# UIモック作成用プロンプト

> このプロンプトを Claude Design / v0.dev / Figma AI (Make Designs) に渡して、UIモックを生成してください。

---

## 使い方

| ツール | 投入方法 |
|---|---|
| **v0.dev** | 下記プロンプト全文をそのままペースト |
| **Figma AI (Make Designs)** | 画面ごと（■ 画面1〜3）に分割して投入 |
| **Claude Design** | 全文を一括で渡してOK |
| **Google Stitch** | 画面単位で投入推奨 |

---

## プロンプト本文

```
あなたはUIデザイナーです。以下の仕様に基づき、AI自動テスト検証用Webアプリケーションの
UIモック（全3画面）を作成してください。

■ デザインシステム
- ベースUI: shadcn/ui コンポーネントに準拠
- スタイリング: Tailwind CSS ユーティリティクラス想定
- カラーモード: ライト/ダーク両対応
- レイアウト: モバイルファースト（sm / md / lg ブレイクポイント）
- フォント: Inter または Noto Sans JP

■ 画面1: 認証画面 (/login)
- 画面中央にカード型レイアウト
- フィールド:
  - メールアドレス（Input type=email）
  - パスワード（Input type=password）
- ボタン:
  - 「ログイン」（Primary、フル幅）
  - 「Sign in with GitHub」（アイコン付き Outline ボタン）
  - 「Sign in with Google」（アイコン付き Outline ボタン）
- 区切り: OAuthボタンとの間に「または」のセパレーター
- 状態表現:
  - 通常状態: デフォルトのshadcn/uiスタイル
  - エラー状態: border-destructive（赤枠）+ フィールド下部にエラーテキスト（例: 「メールアドレスの形式が正しくありません」）
  - ローディング状態: ログインボタンにスピナー + テキスト「ログイン中...」

■ 画面2: 検証用入力画面 (/forms)
- レイアウト: 左サイドバー（240px幅） + 右メインエリア
- サイドバー:
  - アプリロゴ
  - ナビゲーションリンク（入力タイプ別のアンカー）
    - テキスト入力
    - セレクト・コンボボックス
    - 日付選択
    - チェック・スイッチ
    - 条件付きバリデーション
- メインエリア: shadcn/ui コンポーネントをカード単位で配置
  - Card 1「テキスト入力」:
    - Input（テキスト、メール、数値）× 3フィールド
    - 各フィールドにラベル + ヘルパーテキスト
  - Card 2「セレクト・コンボボックス」:
    - Select（単一選択）
    - Combobox（検索付き選択）
  - Card 3「日付選択」:
    - DatePicker（カレンダーポップオーバー付き）
  - Card 4「チェック・スイッチ」:
    - Checkbox（複数選択）
    - Switch（トグル）
    - RadioGroup（単一選択）
  - Card 5「条件付きバリデーション」:
    - カテゴリ Select（選択肢: カテゴリA / カテゴリB / その他）
    - 「その他」を選択すると「詳細説明」Textarea が必須に変わり、赤いアスタリスク（*）が表示される
  - 各カードの下部に個別の Submit ボタン
- 状態表現:
  - エラー状態: 各フィールドの赤枠（border-destructive）+ フィールド直下にエラーメッセージ
  - ローディング状態: Submit ボタンにスピナー表示
  - 無効状態: 未入力時のボタングレーアウト（disabled）

■ 画面3: 管理者 / 一般ユーザー画面 (/admin, /user)
- 共通ヘッダー:
  - アプリ名「AI Test Lab」
  - ナビゲーションリンク
  - 右端: ログインユーザー名 + ロールバッジ（Admin=紫 Badge, User=青 Badge）
  - ダークモードトグル（Sun/Moon アイコン）
- /admin ダッシュボード:
  - KPIカード 4枚（横並びグリッド）: 総ユーザー数 / アクティブセッション / テスト実行回数 / エラー率
  - データテーブル（shadcn/ui Table）: ユーザー一覧（名前 / メール / ロール / 最終ログイン）
- /user プロファイル:
  - アバター + ユーザー名 + メールアドレスのプロファイルカード
  - 「プロファイル編集」ボタン
- 403エラー画面:
  - 「アクセス権限がありません」のメッセージ
  - 「ホームに戻る」ボタン

■ 全画面共通
- ヘッダー: アプリ名「AI Test Lab」+ ナビゲーション + ダークモードトグル
- フッター: 「© 2026 AI Test Lab. Built for AI-Driven Testing.」
- レスポンシブ: モバイル時（375px幅）はサイドバーをハンバーガーメニューに折りたたむ
- ダークモード: 背景をslate-950系、カードをslate-900系に

■ 出力指示
- 各画面につき「通常状態」と「エラー状態」の2パターンを作成すること（計6パターン）
- 各画面につき「モバイル表示（375px幅）」と「デスクトップ表示（1280px幅）」を作成すること
- コンポーネントはshadcn/uiのデフォルトスタイルを活かし、過度なカスタマイズは避けること
```
